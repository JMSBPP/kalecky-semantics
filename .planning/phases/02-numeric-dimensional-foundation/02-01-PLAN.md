# Plan 02-01: Dimensional Kernel — Live Co-Design Ledger

<objective>
Build the dimensional kernel bottom-up as live in-session co-design increments. This plan is a LEDGER, not an executor script: each increment is discussed, its tests drafted and approved by the user in-conversation, then implemented RED→GREEN and ticked off here. No subagents. (Process decision recorded in PROJECT.md Key Decisions, 2026-08-15.)
</objective>

<process_per_increment>
1. Discuss laws live (resolve any open question from 02-RESEARCH.md for this increment)
2. Draft test code in-session; user approves (laws + at least one concrete example)
3. Commit `test(kalecky): …` (RED) → implement → `cabal test kalecky-test` green → commit `feat(kalecky): …` (GREEN)
4. Tick the increment below; contradictions with an approved test stop the increment and get surfaced
</process_per_increment>
